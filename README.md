# 峡谷之巅

一款网页版 3D 五对五推塔对战游戏（原创作品）。你操控一名英雄，带着 4 名电脑队友，对抗 5 名电脑对手，先推掉对方水晶的一方获胜。

**在线试玩：<https://dianguanboss.github.io/xiagu/>**（电脑和手机浏览器直接打开；手机请横屏）

- 画面、模型、图标、音效、音乐全部由程序现场生成，**不依赖任何外部美术或音频文件**。
- 只用到一个第三方库：Three.js（已放在 `lib/`，不需要联网）。
- 电脑（键盘鼠标）和手机/平板（触屏）都能玩，打开时自动识别。

---

## 一、怎么启动

不想装任何东西，直接打开上面的在线地址就能玩。下面是在自己电脑上运行的方法，需要 Python 3（macOS 自带）。

**方法 1：双击启动（macOS）**

双击项目根目录的 `start.command`。它会启动本地服务并自动打开浏览器。

**方法 2：命令行启动**

```bash
python3 serve.py
```

然后用浏览器打开 <http://localhost:8765>。推荐 Chrome、Edge 或 Safari 的最新版本。

**用手机玩**

1. 手机和电脑连同一个 Wi-Fi。
2. 照上面的方法在电脑上启动服务。启动后终端会打印一行 `局域网访问: http://192.168.x.x:8765`。
3. 在手机浏览器打开这个地址，然后横屏。点一下屏幕会自动进入全屏。

> 必须通过服务打开，不能直接双击 `index.html`：浏览器禁止本地文件加载模块。

## 二、游戏流程

主菜单 → 选英雄（可选分路和召唤师技能）→ 加载 → 对局 → 结算 → 回主菜单

- **设置**：音乐/音效音量、画质（自动/低/中/高）、电脑难度（简单/普通/困难）、镜头是否锁定英雄。
- **观战**：主菜单的「观战」可以看 10 个电脑互打，支持 1～8 倍速和自由镜头，适合检验平衡。

### 地图与规则

| 内容 | 说明 |
|---|---|
| 三条路 | 对抗路（上）、中路、发育路（下），每条路两方各有一塔、二塔、高地塔 |
| 水晶 | 有攻击能力；高地塔被推后才会受到伤害。推掉对方水晶即获胜 |
| 泉水 | 快速回血回蓝；对敌方英雄有致命伤害 |
| 小兵 | 15 秒出第一波，之后每 30 秒一波，每 3 波带一个炮车；推掉高地塔后该路出超级兵 |
| 野区 | 红 Buff（普攻灼烧减速）、蓝 Buff（冷却缩减、回蓝），以及狼群、甲虫、鸟群、野猪等普通营地 |
| 炎鳞龙 | 2 分钟出现；击杀后全队获得金币、经验和 90 秒攻击强化 |
| 远古守卫 | 6 分钟出现；击杀后全队获得回复和减伤，兵线强化 90 秒 |
| 成长 | 金币、经验、1～15 级。每级 1 个技能点，大招 4/8/12 级可升，小技能等级不超过英雄等级的一半 |
| 装备 | 28 件，分攻击/法术/防御/移动/打野五类；任何位置都能购买，出售返还 60% |
| 回城 | 6 秒读条，受伤、移动、被控或放技能会被打断 |
| 复活 | 死亡后按等级和对局时间等待复活 |

## 三、操作

### 电脑（键盘 + 鼠标）

| 按键 | 作用 |
|---|---|
| 鼠标右键 / 左键 | 点地面移动，点敌人攻击；按住右键可持续跟随鼠标移动 |
| W A S D / 方向键 | 直接控制移动 |
| 空格 / J | 自动攻击最近的目标（优先英雄） |
| Q / E / R | 一技能 / 二技能 / 大招。按下进入瞄准，松开或点左键释放，点右键取消 |
| 1 / 2 / 3 或 Ctrl+Q/E/R | 升级对应技能 |
| F | 召唤师技能（闪现 / 惩击 / 治疗） |
| B | 回城（再按一次取消） |
| H | 停止当前动作 |
| C 或 P | 打开商店 |
| Tab（按住） | 查看战绩表 |
| Y | 切换镜头锁定 / 自由镜头 |
| 鼠标滚轮 | 镜头远近 |
| 小地图 | 左键按住看那里，右键让英雄走过去 |
| Esc | 暂停菜单（继续 / 设置 / 操作说明 / 投降 / 退出） |

### 手机 / 平板（触屏）

| 操作 | 作用 |
|---|---|
| 左下摇杆 | 移动（按在屏幕左下区域任意位置，摇杆会跟过来） |
| 右下大按钮 | 普通攻击；旁边两个小按钮分别是「补刀」（打残血小兵野怪）和「推塔」 |
| 技能按钮 | 轻点 = 自动瞄准释放；按住拖动 = 手动瞄准，松手释放；拖到「取消」区放弃 |
| 技能上的「＋」 | 升级技能 |
| 召唤师技能 / 回城 | 技能区旁的两个按钮 |
| 点场景里的敌人 | 攻击它 |
| 左上小地图 | 按住查看那里 |
| 左侧金币按钮 | 打开商店；下面的推荐装备可一键购买 |
| 右上按钮 | 战绩、镜头锁定、暂停 |

## 五、怎么验证

### 一键自测（不需要浏览器）

```bash
tests/run.sh
```

依次做三件事，最后一行出现「✅ 全部通过」即为正常：

1. **语法检查**：检查全部源码模块。
2. **单元测试**（`tests/unit.js`）：
   - 音效与飘字的分配规则；
   - 商店推荐、买鞋补差价、6 格上限、出售返还；
   - 升级与技能加点规则、自动加点；
   - 闪现距离与冷却、回城与打断；
   - 开局流程。
3. **批量电脑对战**（`tests/sim_batch.js`）：三种难度各打 2 局完整对局，检查每局都能在 45 分钟内正常分出胜负、没有出错。`tests/run.sh full` 每种难度打 6 局。

单独看一局的详细过程：

```bash
/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc -m tests/sim_match.js -- 42 hard 30 -v
```

参数依次是：种子、难度、最长分钟数、`-v` 打印过程。

### 浏览器里检查

| 地址 | 用途 |
|---|---|
| `http://localhost:8765/` | 正常游戏 |
| `?spectate=1&speed=4` | 直接进入 4 倍速观战 |
| `?play=yanji&difficulty=hard` | 直接用炎姬开一局困难 |
| `?touch=1` | 在电脑上强制显示触屏操作界面 |
| `?models=placeholder` | 用简易几何体代替精细模型（排查模型问题） |
| `tests/model_viewer.html` | 模型检视台：逐个查看英雄、小兵、野怪、建筑模型和动作 |
| `tests/audio_test.html` | 音效试听：逐个播放全部合成音效 |

## 六、代码结构

```
index.html          页面骨架与模块映射
style.css           全部界面样式
serve.py            本地服务（禁缓存，同时打印局域网地址）
start.command       macOS 双击启动
lib/                Three.js
src/
  main.js           入口：读取网址参数、识别触屏、启动游戏
  game.js           总调度：菜单 ↔ 对局切换、主循环、事件分发到画面/音效/界面
  config.js         全局数值：经济、时间、视野、经验表
  settings.js       设置的保存与读取
  input.js          键鼠与触屏输入、技能瞄准
  eventsounds.js    对局事件 → 音效和飘字（纯函数，可单测）
  data/             静态数据：英雄、装备、地图、小兵/防御塔/野怪
  sim/              对局逻辑（与画面完全分离，可无界面运行）
    world.js        世界：步进、出兵、野怪刷新、结算、击杀奖励
    unit.js         单位基类：属性、增益减益、移动
    hero.js         英雄：等级、技能、装备、召唤师技能、回城
    skills.js       10 名英雄 30 个技能的实现
    combat.js       伤害、治疗、控制效果
    entities.js     投射物、区域效果
    nav.js          寻路与碰撞
    match.js        开局：组队、分路、挂上电脑
    ai/bot.js       电脑：对线、补刀、打野、支援、团战、推塔、撤退，三档难度
  render/           3D 画面
    renderer.js     场景、镜头、光照、单位同步
    terrain.js      地形、河道、草丛、墙体
    models/         程序生成的精细模型与动作
    placeholder_models.js  简易模型（备用）
    fx.js particles.js     技能特效与粒子
    fog.js          战争迷雾
    indicators.js   技能指示器、点击标记
    overlay.js      血条、名字、飘字
  ui/               界面：主菜单/选人/加载/结算、对局界面、商店、战绩表、小地图、图标
  audio/audio.js    音效与背景音乐（全部实时合成）
tests/              自测脚本与检视页面
```

**设计要点**

- 对局逻辑以每秒 30 步的固定步长运行，和画面帧率无关。逻辑通过「事件」通知画面、音效和界面，所以整局可以在命令行里无界面跑完，用来做自动测试。
- 同一个种子开局，过程完全一致，方便复现问题。

## 七、已知不足

- **手机性能**：团战时全场约 1500 次绘制。较老的手机如果卡，可在设置里把画质调到「低」。
- **模型小瑕疵**：
  - 烈锋待机时剑的角度略别扭；
  - 红 Buff 蜥蜴下巴偏宽；
  - 鸟群死亡时翅膀朝上；
  - 炮车轮子略陷进地面。
- **英雄重复**：只有 10 名英雄，两边常会出现同一个英雄。
- **难度**：电脑队友固定是「普通」水平，设置里的难度只改变对手。选「困难」时对手明显更强，需要玩家自己多出力。
